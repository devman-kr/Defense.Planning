## 알아 둘 것

- 커밋은 리드(주 세션)만 하고, 서브에이전트는 맡은 파일만 고친다(계획서 2절).
- 어느 세션이든 끝날 때 다이제스트 훅이 로그 저장소에서 `git add -A` 로 커밋한다 — 로그 이행은 적용과 커밋을 한 번에.
- `python3 -I` 는 스크립트 폴더를 import 경로에 넣지 않는다 — 로그 훅은 `fm_lint` 를 불러오지 않는다.
- P00 세션(세션 10)은 P02 가 끝날 때까지 기다린다. 마감 때 P00 NOTES 에 넘길 것을 적는다(계획서 0절).
