# P04 — 매끈한 모델 시험(Blender 서브디비전 · Unity 셰이딩 3종)

**상태** 종결(2026-11-02) — 계획서 8절 완료 기준 전부 ✔ · **등재** 2026-11-02 · **다음 행동** 없음. 결과는 `Defense.Unity` `main` 머지 `86431e0`(정리 `356995d` · 문서 `e34f1f5` · `1078a8c`), 최종 전후 시트 [`03_작업기록/assets/최종_세로_전후_20261102.png`](03_작업기록/assets/최종_세로_전후_20261102.png), 작업 보고 넷 `Defense.Unity/z.docs/work_reports/20261102/`. 아트 방향 미결 6 · 볼륨 프로필 · FBX 경로는 `DEF-M03`(D-10 · D-11 — P01 NOTES 4번). 끝난 것: S1 · S2 · S3(Opus 5.5) · S4(판정 · 머지 · 종결) — 커밋은 [`03_작업기록/작업색인.md`](03_작업기록/작업색인.md).

**한 줄**: P03 이 만든 샘플 모델 3종(슬라임 · 박쥐 · 등불 탑)은 로우폴리 · 플랫이다. 사용자가 원하는 결과 레퍼런스(Supercent)는 매끈하고 둥근 모델이므로, 같은 CLI 파이프라인(Blender `bpy` → FBX → 창 없는 에디터 → 캡처)으로 매끈 판을 만들고 셰이딩 3종으로 캡처해 **그림으로 비교**한다. 이 과제는 기획서 9절 · 스타일 보드를 고치지 않는다 — 아트 방향 결정(D-nn · G-nn)은 결과를 본 사용자가 한다. 2026-11-02 S1 이 끝나 사용자가 셀 캡처를 보고 「참 마음에 듦」 — S3 에서 카툰 렌더링(외곽선 · 그림자 · 램프 · 림 · 후처리)을 깊이 본다(D-07). S3 는 사용자와 승인 지점 넷을 거쳐 외곽선 A(외피) · 받는 그림자 양자화 · 캐릭터 자기 그림자 끔 · 블롭 그림자 · 림 · 스페큘러 · 램프 텍스처를 `Defense/PaletteToon` 하나로 매끈 판 5종에 적용했고(사용자 「결과 매우 만족」), S4 가 검산 · 머지해 종결했다(D-08).

## 알아 둘 것

- 비교 실험이 아니다 — Opus 5.5 한 모델이 S1 → S2 → S3 를 같은 worktree · 브랜치에서 이어서 한다. S3 는 사용자가 지켜보는 세션이다 — 승인 지점 넷에서 대조 시트를 보고 고르고, `Assets/Settings/`(렌더러 기능) 변경은 그 자리에서 전후 값을 보고 허락한다. 격리 조건이 없으므로 실행 세션은 Planning(이 폴더 · P03 비교표 · P01 NOTES) 을 읽어도 된다. 쓰지는 않는다.
- 좀비는 기획서 5절 적 목록에 없다(사용자 요구 원문의 「괴물 · 좀비」에서 온 시험 샘플). 채택하면 D-nn → 기획서 5절.
- 레퍼런스 스크린샷은 세션이 스토어 공개 페이지에서 **보기만** 한다(D-04). 저장소 · `z.captures` · 확인 페이지에 넣지 않는다(G-03).
