## 프롬프트 본문 (여기부터 붙여 넣는다)

이 지시서는 Claude Opus 5.5 기준으로 썼다(가이드 확인일 2026-09-29). 세션 모델이 다르면 시작 전에 사용자에게 알린다.

### 맡는 일
- 과제 `P04`(매끈한 모델 시험) · 세션 `S2` · 스트림 B(Unity) · 마일스톤 없음(시험). S1 이 같은 브랜치에서 끝낸 매끈 판 기법 · 가져오기 코드 · 셰이딩 머티리얼을 그대로 쓴다.
- 치비 인간형 둘을 매끈 판으로 만든다 — **해골 궁수**(기획서 5절: 사거리 밖에서 멈춰 쏜다 — 활이 있는 뼈다귀)와 **좀비**(사용자 요구 원문의 「괴물 · 좀비」 — 기획서 5절에는 없는 시험 샘플, 채택은 사용자). Blender 창 없이 뼈대 · 가중치 · 동작 각 3(Idle · Walk · Shoot 또는 Attack)을 만들어 FBX 로 내보내고 Unity 샘플 씬에 더해 캡처 · 녹화한다. 끝나면 사용자가 인간형이 이 파이프라인에서 어떻게 나오는지(관절 접힘 · 비례 · 소품 부착) 그림으로 보고, 인간형 특유의 함정이 실측값으로 남는다.
- 비례 · 결(레퍼런스 Supercent): 키는 슬라임 높이의 약 2배이고 탑보다 낮다. 머리가 키의 약 40 %, 손 · 발이 크고 손가락이 없다. 눈은 점 둘(어두운 셀), 입은 없다. 면은 둥글고 매끈(S1 기법), 색은 팔레트 셀 단색. 해골 궁수 — 뼈 흰색 셀 · 갈비 · 활(별도 메시, 왼손 뼈에 붙음). 좀비 — 초록 피부 셀 · 찢어진 옷 셀(두 색) · 팔을 앞으로 뻗은 자세.

### 진행 방식
- S1 지시서와 같다 — 사용자는 지켜보지 않는다, 끝까지 계속한다, 적힌 대상 전부(「둘 다」 · 「동작 각 3」)에 적용한다, 더 나은 방법은 한 문장으로 적고 요청대로, 실제로 돌린 검사만 완료로, 미지수는 실측해서 숫자 · 오류 원문으로, 같은 오류를 세 번 넘게 반복하지 않는다.
- 시작 전 한 줄(「지시서와 다른 점」)을 알리고 착수한다. 먼저 S1 작업 보고의 9절 「발견」과 함정 표를 읽는다 — 거기 적힌 API · 옵션 · 수치를 그대로 쓴다.
