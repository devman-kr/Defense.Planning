# P04 — 매끈한 모델 시험(Blender 서브디비전 · Unity 셰이딩 3종)

**상태** 계획 · **등재** 2026-11-02 · **다음 행동** 사용자가 [지시서 S1](02_계획/지시서/20261102_S1_Unity_P04_매끈판_셰이딩.md) 을 검토해 Opus 5.5 세션에 붙여 넣는다(계획서 7절 (a)). S2 는 S1 보고를 본 뒤.

**한 줄**: P03 이 만든 샘플 모델 3종(슬라임 · 박쥐 · 등불 탑)은 로우폴리 · 플랫이다. 사용자가 원하는 결과 레퍼런스(Supercent)는 매끈하고 둥근 모델이므로, 같은 CLI 파이프라인(Blender `bpy` → FBX → 창 없는 에디터 → 캡처)으로 매끈 판을 만들고 셰이딩 3종으로 캡처해 **그림으로 비교**한다. 이 과제는 기획서 9절 · 스타일 보드를 고치지 않는다 — 아트 방향 결정(D-nn · G-nn)은 결과를 본 사용자가 한다.

## 알아 둘 것

- 비교 실험이 아니다 — Opus 5.5 한 모델이 S1 → S2 를 같은 worktree · 브랜치에서 이어서 한다. 격리 조건이 없으므로 실행 세션은 Planning(이 폴더 · P03 비교표 · P01 NOTES) 을 읽어도 된다. 쓰지는 않는다.
- 좀비는 기획서 5절 적 목록에 없다(사용자 요구 원문의 「괴물 · 좀비」에서 온 시험 샘플). 채택하면 D-nn → 기획서 5절.
- 레퍼런스 스크린샷은 세션이 스토어 공개 페이지에서 **보기만** 한다(D-04). 저장소 · `z.captures` · 확인 페이지에 넣지 않는다(G-03).
