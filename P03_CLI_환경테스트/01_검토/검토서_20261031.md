# P03 CLI 환경 시험 검토서 — Blender · Unity CLI 로 샘플 적 캐릭터를 만들어 Unity 샘플 씬에서 보이기

**이 문서의 위치**: 사용자 요청(2026-10-31) 「Unity · Blender 의 각 CLI 환경을 테스트하고 스크린샷으로 확인 — Blender 로 목표하는 게임 샘플 에셋(심플한 적 캐릭터, Supercent 캐릭터 같이)을 만들고 Unity 샘플 씬에서 보이는 것을 스크린샷 · 녹화로」를 과제 P03 으로 여는 검토다. 실행은 다른 세션이 한다. 결정 경위는 [결정기록.md](../결정기록.md), 사전 확인 산출물은 작업 공간 `z.tmp/p03/`(git 밖) · 렌더는 `z.captures/20261031/`.

**읽는 사람**: 결정자(1 · 4 · 6절) · 실행 세션(3 · 7 · 8절).

**용어**: 열림 경로 = 세션이 띄운 창 없는 에디터를 `unity command` 로 다루는 것(G-12) · 닫힘 경로 = `unity test` · `unity build`(batchmode) · 사본 프로젝트 = `Defense.Unity` 를 git 밖에 복제한 일회용 프로젝트.

## 1. 결론

- P03 은 **CLI 환경 · 파이프라인 시험** 과제다 — Blender(창 없이 `bpy`) → FBX → Unity(창 없는 에디터 + `unity command`) → 샘플 씬 → 캡처 · 녹화 — 를 한 번 끝까지 돌려 사용자가 그림으로 확인하고, 그 과정에서 만나는 함정을 `DEF-M03`(아트) 전에 적어 둔다.
- 범위는 4.1 의 **B(표준)** 를 권한다 — 샘플 에셋 3종(슬라임 · 박쥐 · 등불 탑), Unity 샘플 씬(잔디 섬 · 탑 · 적 여럿 · 세로 카메라), CLI 정지 캡처, 애니메이션 프레임 → MP4, 파이프라인 함정 둘(클립 이름 · 루트 회전) 실측. 하루(M) 안에 끝나고 사용자가 보는 것이 가장 많다.
- Unity 쪽은 **사본 프로젝트(git 밖)** 에서 한다 — `Defense.Unity` 는 깨끗하게 두고, 결과를 본 뒤 들일지 정한다(4.2 · 4.3). 샘플 에셋이 「첫 아트 에셋」이 될지는 `DEF-M03` 결정이지 이 과제가 정하지 않는다.
- Blender 쪽은 이미 한 번 돌아간다 — 이 세션의 사전 확인(3절)에서 창 없는 Blender 5.2.3 이 5.35초에 모델 3 · 동작 6 · FBX 6 · 렌더 7장을 냈다. 남은 것은 다듬기(날개 색 · 날개 축)와 Unity 쪽 전부다.

## 4. 방안

### 4.1 시험 범위

| 범위 | 내용 | 사용자가 보는 것 | 규모 | 비고 |
|---|---|---|---|---|
| **A 최소** | Blender 스모크(이미 됨) + Unity 열림 경로 한 바퀴 — 창 없는 에디터 기동 → FBX 1개 가져오기 → 빈 씬 배치 → `capture game_view` 1장 → 종료 | 캡처 2~3장 | S(반나절) | 「CLI 가 된다」만 확인. 샘플 씬 · 녹화 없음 |
| **B 표준(권장)** | 샘플 에셋 3종 다듬기(슬라임 · 박쥐 · 탑 — 날개 색 · 축 수정) + Unity 샘플 씬(잔디 섬 · 등불 탑 · 슬라임 8 · 박쥐 4 · 세로 9:16 카메라 · 방향광 · 등불 점광) + CLI 정지 캡처(세로 1080×1920 · 가로 1920×1080) + 애니메이션 프레임 48장(24 fps 2초, 클립을 시간으로 샘플링해 렌더) → MP4(Blender ffmpeg) + 함정 둘 실측(클립 이름 벗기기 · 루트 X 270° — `bake_space_transform` 두 변형 비교) + 확인 페이지(claude.ai 비공개) | 정지 캡처 2 · 동영상 1 · Blender 렌더 7 · 발견 기록 | M(1일) | 플레이 모드 없이 에디터 렌더만 — 미실측 위험이 가장 작다 |
| **C 확장** | B + 플레이 모드(Animator 컨트롤러를 CLI 로 만들고 `editor.playmode start` → `capture game_view --source screen`) + 언릿 · 단순 셀 셰이더 맛보기 + WebGL 또는 Android 빌드 한 번과 그 화면 캡처 | + 플레이 모드 캡처 · 빌드 1 | L(2일) | `source=screen` 은 창 없는 에디터에서 안 될 수 있다(게임 뷰 창이 없다). 빌드는 P00 실측 240~377초 |

B 에서 C 로 가는 비용은 작지만(플레이 모드 · 빌드는 P00 에서 한 번씩 돌았다), C 의 셰이더 · 빌드 캡처는 `DEF-M03` · `DEF-M05` 의 일이라 시험 과제에서는 뺀다.

### 4.3 샘플 에셋 · 스크립트의 운명

- **샘플 에셋(FBX · 팔레트)**: ① 시험 뒤 버린다(git 밖에 남김) ② 「첫 아트 에셋」으로 `Assets/_Project/Art/` 에 들인다. 권장 ① — 들일지는 결과를 보고 `DEF-M03` 에서 D-nn 으로(5절의 어긋남도 그때).
- **`bpy` 스크립트**: 공개 저장소에 두면 그 폴더만 GPL-3.0-or-later(G-17). 후보 — `Defense.Unity/Tools/Blender/`(폴더 `LICENSE` 따로 — 파이프라인이 포트폴리오에 보인다) · Planning `P03/04_자산/`(Planning 도 공개 — 같은 GPL 문제, 과제 자료로는 어색) · git 밖(`z.captures/` — 재현은 되지만 공개되지 않는다). 권장: P03 동안은 git 밖, 에셋을 들이는 날 `Defense.Unity/Tools/Blender/` 로.

### 4.4 캐릭터 종류 · 스타일 기준

- 「Supercent 캐릭터 같이」의 근거는 `_공통/조사/Supercent_스타일보드.md` 3절 **[추정]**(로우폴리 · 단색 면 · 큰 머리 · 점 눈 · 과장된 바운스)이다 — 레퍼런스 캡처(실행 요청 5)는 아직 없다.
- 후보: ① **슬라임 + 박쥐**(기획서 5절의 첫 두 적 · 비휴머노이드 · 뼈 2~3 · 사전 확인 끝) ② ① + 해골 궁수(휴머노이드 — 뼈 10 이상 · 걷기 · 쏘기 동작 · 직접 만들면 L 규모, 또는 CC0 팩) ③ ① + 탑 꾸미기 샘플(모델 교체 — 기획서 7절). 권장 ①(시험에 필요한 만큼 — 두 가지 뼈대 유형(스쿼시 · 회전)을 다 본다).
- 스타일은 추정대로 진행하고 캡처가 오면 `DEF-M03` 에서 맞춘다(권장) · 캡처를 먼저 받고 진행한다.

### 4.5 캡처 · 녹화 수단

| 무엇 | 수단 | 상태 |

### 4.6 세션 구성

- 한 세션이 S1(Blender) → S2(Unity) 순서로(한 기기 G-01 — Blender 가 끝난 뒤 에디터를 띄운다). 받는 모델은 구현 역할 **Opus 5.5**(프롬프트 작성 가이드 1절). 지시서 하나에 S1 · S2 를 절로 둔다(권장).

## 5. 대안 · 외부 의견과의 대조

## 8. 위험과 전제

- **창 없는 에디터의 카메라 렌더**가 그림을 내는지 미실측 — pipeline 이 `source=camera` 를 「화면 밖 렌더」로 제공하므로 될 것 [추정]. 안 되면 `-batchmode` 없이 창 있는 에디터를 세션이 띄우는 대안(G-12 는 「창 없는」이 기본이지 금지는 아님)을 지시서에 적는다.
- **플레이 모드 `source=screen`** 은 게임 뷰 창이 있어야 할 가능성이 높다 — B 범위에서는 쓰지 않는다.
- **클론한 `Library/`** 가 다른 경로에서 그대로 열리는지 미실측 — 안 열리면 `Library/` 를 지우고 재임포트(수 분).
- **스타일은 추정**이다(4.4). 사용자가 「Supercent 같지 않다」고 하면 `DEF-M03` 의 일이지 파이프라인 결함이 아니다.
- **GPL**: `bpy` 스크립트를 공개 저장소에 올리는 순간 그 폴더가 GPL 이다(G-17). P03 동안은 git 밖.
- 16 GB 한 기기 — Blender · 에디터 · 인코딩을 차례로. 에디터를 띄운 채 Blender 를 돌리지 않는다.
