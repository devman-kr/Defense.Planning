**상태** 계획 — 실행 대기(S0 준비 ✔) · **등재** 2026-10-31 · **다음 행동** 사용자가 [계획서](02_계획/계획서_20261031.md) 7절 (a) 로 worktree 를 준비하고 **S1 Sonnet 5.5 세션**에 [지시서 S1·S2](02_계획/지시서/20261031_S1S2_Unity_P03_실행.md) 본문을 붙여 넣는다 → (b) 격리 → S2 Opus 5.5 → (c) → (d) 복원 → S3 판정([지시서 S3](02_계획/지시서/20261031_S3_판정.md), Fable)
